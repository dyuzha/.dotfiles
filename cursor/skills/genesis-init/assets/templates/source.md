# Источник

Шаблон. Его заполняет `/genesis-source` в файле `source.md`. Этот файл в `templates/` не перезаписывать.

Пустые метки `_(пусто)_` значат, что источника нет и команды берут факты из мысли.

### Название

_(пусто)_

### Адрес или путь

_(пусто)_

### Текст

_(пусто)_

### Граница

В ролик попадает только то, что есть в тексте выше. Имён, чисел, механизмов и причин со стороны нет.
